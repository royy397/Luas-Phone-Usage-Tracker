# Luas-Phone-Usage-Tracker
Luas Phone Usage Tracker records passenger phone use on my daily Luas journeys. The dataset includes the date, day, time, stop, weather, total passengers, and number using phones. The aim is to identify patterns and trends in phone usage using data analysis and visualisations.

## Project Description

This project investigates phone usage on the Luas using data collected during my daily journeys to and from college. For each journey, I recorded the date, day, time, destination, weather, total number of passengers, and the number of passengers using their phones.

The data is stored in a CSV file and will be analysed using Python, Pandas, and SQLite. The aim of the project is to identify patterns and trends in passenger phone usage and determine whether factors such as time of day, weather conditions, destination, or day of the week have any effect on how often passengers use their phones.

## Questions

1. Does the time of day affect phone usage on the Luas?

2. Does the weather affect the percentage of passengers using their phones?

3. Do passengers use their phones more on certain days of the week than others?
