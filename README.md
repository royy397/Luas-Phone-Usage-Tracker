# Luas-Phone-Usage-Tracker
Luas Phone Usage Tracker records passenger phone use on my daily Luas journeys. The dataset includes the date, day, time, stop, weather, total passengers, and number using phones. The aim is to identify patterns and trends in phone usage using data analysis and visualisations.

## Questions

1. Does the time of day affect phone usage on the Luas?

2. Does the weather affect the percentage of passengers using their phones?

3. Do passengers use their phones more on certain days of the week than others?
